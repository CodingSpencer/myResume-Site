# My Resume Site

A lightweight personal resume website built with Astro, Svelte, and Express.

## Stack

- Astro for the static site shell and page rendering
- Svelte for component-level UI patterns when needed
- Express for a simple API and local preview server

## Scripts

- `npm install`
- `npm run dev` — starts the Express API and the Astro app together
- `npm run build` — builds the static production site
- `npm run preview` — serves the built app using Express

## Structure

- `src/pages/index.astro` — main resume page
- `src/data/resume.js` — resume content data
- `src/styles/global.css` — styling
- `server/index.js` — Express API and local preview server

## Notes

This starter project is meant to be a polished personal resume landing page with strong typography and a clean one-page layout. It is intentionally simple and easy to customize for your own experience and credentials.
